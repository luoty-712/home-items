# PPT 用图说明

这些图都是 **PNG、透明背景或自带背景**，可以直接拖进 PowerPoint / WPS 使用。
分辨率按 1920×1080 版式出图，投影和打印都够。

## 插入 PPT 的两种姿势

**A. 直接用整页图（最省事）**
新建一页 → 插入 → 图片 → 选 `整页-1920x1080.png` → 拉满整页（铺满 16:9 版面）。

**B. 用透明拼版图，文字自己排（推荐，风格统一）**
插入 `三屏并排.png` → 缩放到占版面右侧 60% → 左边用你们 PPT 原有的标题样式写"输入名字，秒出位置"。
这样文字是**可编辑**的，改措辞不用重做图。

## 三个注意点

1. **图里的字是图片，不能在 PPT 里改**。要改文案就选方案 B（图里只留界面，字自己打）。
2. **PPT 里点不动**。PowerPoint 嵌网页只有"对象/ActiveX"那种老办法，放映时还是死的。
   现场演示请另开浏览器（或手机上把网页"添加到主屏幕"后用），PPT 只负责展示截图。
3. 如果投影偏小、看不清界面细节，优先用 `单屏-*.png` 放大讲某一屏，别硬塞四屏。

## 想更"活"一点

可以录一段 5 秒操作（点开 → 搜 cd → 出现 3 条 → 点进详情）存成 GIF 或 MP4，
PPT 里「插入 → 视频」会自动循环播放。需要的话说一声，我可以直接生成。

## 图片怎么来的

用 headless 浏览器把真实页面（`index.html`）按 430×932 手机视口截图，
再套上手机外壳、按 2 倍分辨率导出，所以界面就是真实的界面，不是画的示意图。
